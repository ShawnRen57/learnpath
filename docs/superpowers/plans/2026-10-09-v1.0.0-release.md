# LearnPath v1.0.0 正式版规划

**目标：** 保持轻量 Skill 的形态，补齐真实使用验证，让用户能够安装、确认计划并持续收到合格学习材料。

**方案：** 沿用现有 SKILL.md、PDF 辅助脚本和课程状态文件。搜索、模型、图片、调度与通知继续使用宿主已有能力；只修复实际使用中发现的问题。

**现有技术：** Agent Skills、Python 3.10+、XeLaTeX、宿主原生调度。

**需求依据：** 用户本次提出的轻量化约束、原始学习 Skill 要求，以及当前 [验证记录](../../validation.md)。用户已授权第一项安装与首次使用验证，2026-10-09 已完成，详见 [验收报告](../../installation-validation.md)。其他工作尚未启动。

## 判断与范围

v0.1.1 的版本号不代表只完成了一小部分。已有六组课程、24 份 PDF、21 项通过的测试，以及安装包校验。核心能力基本成形，缺口集中在正式安装、Agent 自主遵循流程、真实跨日执行和对外支持承诺。

v1.0.0 不增加后台服务、用户账号、数据库、独立调度器或学习管理界面；不增加新的必需运行依赖；不为未实测的平台宣称完整兼容。维持原始 PDF、联网研究、教学插图及计划确认要求。

## 工作安排

### 1. 验证正式安装与首次使用

- [x] 从公开发布包安装到隔离技能目录，不借用开发仓库中的内容与配置。
- [x] 在 Codex 和 DeepSeek Harness 分别确认技能发现、资源读取、环境检查及基础 PDF 生成。
- [x] 记录缺失依赖的安装指引、实际版本与配置；遇到受限能力时，确认给出的说明准确且可执行。

**通过条件：** 按 README 操作能够找到并使用 Skill；不存在未说明的开发机路径、资源或手工修补依赖。若某平台无法完成验证，明确标注其验证范围，不能以文档推测代替实测。

涉及：README.md、docs/deepseek-harness.md、skills/learnpath/references/setup.md、skills/learnpath/references/platforms.md；按发现的问题做最小改动。

### 2. 验证真实学习流程与材料质量

- [ ] 新建一门中文短课程，例如“生态学通识”，由 Agent 从一句主题开始自主追问、研究、编排并生成计划；避免复用已有样例正文。
- [ ] 确认计划批准前不创建定时任务；批准后按批准的计划执行。
- [ ] 在一个已验证宿主上，连续三个自然日通过真实定时触发交付 Day01–03，保存时间、任务及交付证据。
- [ ] 在另一个宿主完成计划、Day01 和一次真实调度触发；这只验证一次触发，不宣称多日可靠性。
- [ ] 补一份英文计划与 Day01，核对语言、字体、布局及链接。
- [ ] 人工核对课程顺序、事实与来源、角色和目标匹配、图片解释作用，以及阅读加练习是否大致适合约定时间；选读时间另计。

**通过条件：** 计划与每日材料满足原始要求；无需人工修改内部状态来推进；定时任务真实执行，PDF 实际交付，天数与交付记录一致。三天验证不等同于长期服务保证。

涉及：隔离课程目录、新的简短验收记录；仅在暴露缺陷时修改 SKILL.md、references/content.md 或现有脚本。

### 3. 核对恢复行为并修复阻断问题

- [ ] 在隔离课程中核对重复触发、生成失败重试、暂停/恢复和课程结束；尽量复用现有测试与短课程，不复制整套课程。
- [ ] 重点检查计划变更后审批是否失效、通知成功但进度未记录时如何核对，以及课程暂停与宿主暂停能力不一致时的行为。
- [ ] 只修复导致流程无法完成、错误推进、重复交付或误导用户的问题。脚本缺陷补对应回归测试；文案修正不新增形式化测试。

**通过条件：** 失败不跳课、重复执行不无故重生成、暂停后不生成新课；结束后定时任务停止，或如实说明宿主限制及后续处理。通知与文件状态非原子更新的限制保持可见。

涉及：tests/test_core.py、tests/test_render.py、skills/learnpath/scripts/、skills/learnpath/SKILL.md、references/platforms.md；按具体发现修改，不提前重构。

### 4. 收敛说明并发布正式版

- [ ] README 保留清晰的安装、主题示例、计划确认和续学/暂停说明；标注“已实测”“文档支持”“未验证”的平台范围。
- [ ] 保留现有六组样例，不为版本升级重新生成全部 24 份 PDF，也不改写旧资料的研究日期。
- [ ] 在最终代码上运行现有必要测试、Skill 校验、安装包解压检查和 PDF 验收；说明实际执行及跳过的项目。
- [ ] 将 Skill 元数据、打包工具、CHANGELOG 和 Release 统一为 v1.0.0；校验公开安装包并更新已有 DSH 展示帖，避免重复发帖。

**通过条件：** 发布包与说明一致，核心流程没有未解决的阻断问题，对外承诺不超过实测证据。

涉及：skills/learnpath/SKILL.md、tools/package_skill.py、dist/、README.md、CHANGELOG.md、docs/validation.md，以及已有社区帖子。

## 实施节奏与停止标准

建议先验证安装，然后启动三天课程；观察期间完成英文材料、恢复行为和说明修订。实际跨日验证至少需要三个自然日，不以加速样例冒充。平台登录、工具能力或依赖问题可能影响进度，发生时记录具体缺口。

满足以上四项即可发布 v1.0.0。多平台扩大实测、更多主题样例和教学效果长期跟踪可在后续版本推进，不作为本次正式版新增功能。正式版表达的是当前范围可用且承诺可信，并不意味着所有宿主环境都已验证。
